# 逐张验收与交付

## 视觉核对

| 位置 | 原片与成图对照 |
| --- | --- |
| 整车 | 车身比例、轴距、透视、轮廓、车门与后视镜数量、门缝 |
| 灯组 | 形状、边界、安装位置、黄色转向灯对齐、原有点亮状态 |
| 轮毂 | 辐条结构、轮胎外径、制动器、中心 Logo 字形 |
| 品牌 | 车头/车尾使用正确标识、文字不缺笔、不替换、不乱移位置 |
| 光影 | 高光顺着曲面、漆面干净有纹理、接地阴影连续、天空与反射一致 |
| 景深 | 原有虚化前景和遮挡关系、清晰中景、合理远景层次 |
| 清场 | 人物含车内与帐篷旁、背景车、气球、电线与残端、相关投影和反射 |
| 内饰 | 座椅缝线、按钮、屏幕、扬声器文字、金属与皮革材质 |

整体好看和结构正确分别验收。结构不符时如实标注，不能以“只用于参考”代替修正后还称最终交付。

## 分辨率与文件大小

- 记录 `width × height`、格式和字节数，必要时附源图与成图各自尺寸。
- “2K”在不同平台含义不同，交付时写具体像素。例如 2048×1365 长边约 2K；1536×1024 不到 2K。
- 3840×2160 与长边 4096 是不同要求，先按实际用途选择；竖屏拼图 2160×3840 只是排版尺寸。
- 放大、插值和超分辨率不能证明原车 Logo 或微小结构真实恢复。以高分辨率原片为最终结构依据。
- 文件 MB 受纹理、位深、编码与压缩影响，不以体积判断画质。

## 服务与批处理

模型版本、价格、积分、登录与套餐权限由服务决定。发布的示例不是速度、费用或效果承诺。需要付费时遵守用户当前预算；不要以历史积分没变化推断对所有账号免费。

推荐保留清单字段：原片哈希、参考文件角色、工具与模型（已知时）、提示词、任务 ID、状态、输出尺寸、视觉问题、人工验收结论。网络失败时先查询任务再重交，避免重复扣费。

原图本地保存，公开示例采用专门选定、去元数据的缩略图。不要把地理位置、用户目录、账号令牌、授权码或全部拍摄底片混入仓库。不同参考图需要有使用权；品牌示例不表示品牌授权或合作。
