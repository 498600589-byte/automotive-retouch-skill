# 按照片填写的编辑模板

参考必须作为实际输入传入；下列文字不会自动寻找或上传文件。不要把所有模板叠在一张图上。

## 静态整车

```text
对输入原片做真实商业汽车摄影精修。
图1：唯一构图与车型结构依据。
图2：同款原车的[轮毂/灯组/标识]细节，仅用于核对对应零件。
图3：仅参考光影过渡与质感，不引入其车辆、建筑或机位。

保留：[车身轮廓、原机位、主体位置、灯组状态、轮毂与标识、特定前景及遮挡关系]。
清理：[逐项写出灰尘、人物、杂物、电线等；区分主体与背景车辆]。
光影：[依据原片光向，柔和提亮暗部，宽高光沿车身曲面过渡，保留接地阴影与真实反射]。
环境：[保留景别层次；按需统一路面，不改变透视与主体比例]。
避免：重绘零件、改变字体与灯组位置、塑料漆面、过度HDR、漂浮轮胎、压平前景。
```

## 内饰与细节

```text
保留座椅缝线、打孔排列、按钮数量、屏幕与扬声器字样、材质分界和原有景深。
只清除[污点/窗外人物或背景车]，优化曝光与色偏，保持皮革、金属和玻璃的差异。
不要编造屏幕内容、改写品牌文字、把材质磨成无纹理表面。
```

## 航拍场地净场

```text
保留原俯拍机位、场地边界与地面品牌文字的准确字形、位置和比例。
去除用户指定的[车辆/人物/杂物]及其投影，连续补全真实地面纹理。
分别确认是否保留赛道锥桶、轮胎轨迹、安全设施；不要把活动场地重建成其他地点。
```

## 局部修正

```text
只修正[原片中具体区域]，参考[对应原件]。
保留已认可的光影、背景、构图与其余区域。
若当前工具不能限制编辑范围，先说明会重绘的风险，不声称已使用蒙版。
```

对于精确 Logo，首选原件像素、合法矢量或分层合成。附加放大参考有助于模型辨认，但没有提供几何一致性的保证。
