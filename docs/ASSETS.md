# 展示素材与使用范围

本仓库示例来自仓库所有者提供并授权用于本次 GitHub 展示的实拍与既有 AI 编辑结果。公开文件仅包含选定静态照片的缩略版、真实版本对比和去元数据的排版图；没有上传全部底片、车辆路跑画面、账号日志或私人目录记录。

图片和汽车品牌标识不在代码的 MIT 授权范围内。摄影作品的权利由相应权利人保留；示例公开展示不授予下载者再分发、广告使用或品牌代言权利。AI 成图的使用还应符合对应服务的适用条款。涉及后续商业使用，请取得相应权利人的许可。

公开素材对应关系与实际像素见 [examples.json](examples.json)。`before` 是缩略后的实拍，`image` 与 `dreamina` 均为该原片对应的实际编辑文件。对比排版没有补造缺失引擎版本。

所有导出预览去除 EXIF/GPS，不保留本地绝对路径。品牌字样、零件设计和内饰屏幕可能在生成中变化；请结合 [展示说明](SHOWCASE.md) 阅读。
