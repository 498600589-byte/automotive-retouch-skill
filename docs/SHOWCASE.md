# 示例怎么阅读

展示的是编辑方向与工作流，不是零件精度保证，也不是模型排名。所有车辆均为静态拍摄；不展示车辆路跑画面。

| 示例 | 观察重点 | 已知边界 |
| --- | --- | --- |
| 茶园静态车 `tea-garden` | 保留左下虚化茶叶及遮挡，整理环境，改善漆面与远景明暗 | 灯带、轮毂和车标仍应回到原片放大核对；生成的地面与植被是重建结果 |
| 草坪静态车 `lawn` | 移除远处人物、优化车身与天空，保留草坪和主体关系 | 天空与局部材质被重新解释，不能称为原片局部像素修复 |
| 内饰 `interior` | 座椅材质、曝光和窗外干扰处理 | 座椅缝线、屏幕字样、窗外细节可能重绘；画面更干净不等于零件已经验收 |

茶园与内饰提供两种对照：原片/Image 横向对比、原片/Image/即梦 9:16 三版对比。草坪仅提供原片/Image，不填补缺失的即梦版本。

`docs/assets/sources` 保存去元数据、等比缩小的展示版。原图展示版长边最多 1600；编辑结果不进行超分放大。图像尺寸和 SHA-256 见 [examples.json](examples.json)。比较图按相同版式完整放入，不裁切原图，也不再做额外美化。

三版对比的 1080×1920 是排版画布；它不能代表各模型直出了相同分辨率。两个引擎的任务时间、提示词、输入预处理和模型版本未做受控统一，因此只作为真实工作样片展示。
